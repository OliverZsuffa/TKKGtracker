# Documentation

## Start here
1. [Project instructions](../.github/copilot-instructions.md) define the request approval workflow and engineering constraints.
2. [Knowledge base](knowledge/README.md) contains reusable architecture and lessons.
3. [Approved decisions](decisions.md) records decisions explicitly approved by Oliver.
4. [Requests](../requests/README.md) explains the request, planning, approval, and handoff process.

## Sources of truth
- The approved request defines scope and expected behaviour.
- Its approved implementation-plan.md defines the intended implementation approach.
- Current code and relevant knowledge describe actual implementation patterns.
- docs/decisions.md contains explicitly approved durable product or architecture decisions.
- Request-specific test results and remaining work belong in the request's notes.md.

Do not treat an unapproved proposal or an inferred detail as a confirmed requirement.
