# TKKGTracker

A static web app for tracking listened episodes of the regular TKKG audio drama series, backed by a Python catalogue scraper and validated JSON data.

## Project workflow

Substantial work is tracked under `requests/`. Each request has a desired outcome, implementation plan, manual testing instructions, and outcome notes. Implementation must wait for explicit approval of the plan.

Reusable project architecture and lessons belong in `docs/knowledge/`. Read the project instructions and relevant knowledge before planning or changing code.

## Current status

The initial catalogue scraper and listening tracker are in planning. See the active request under `requests/` once the planning branch is created.
